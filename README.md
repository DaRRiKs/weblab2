# Лабораторная работа CSE5032, модуль 02

Простой ASP.NET Core Web API для списка задач. Данные находятся в `List<TaskItem>` в памяти процесса и исчезают после остановки приложения. База данных не используется.

## Запуск

Требуется [.NET 8 SDK](https://learn.microsoft.com/dotnet/core/install/windows). Если команда `dotnet` не распознаётся, установите SDK и откройте новый терминал. В папке проекта выполните:

```powershell
dotnet restore
dotnet run
```

Откройте Swagger UI: <http://localhost:5154/swagger>. Через кнопку **Try it out** можно выполнить каждый запрос. Swagger JSON доступен по адресу <http://localhost:5154/swagger/v1/swagger.json>.

## API

| Метод | Адрес | Действие | Успешный ответ |
| --- | --- | --- | --- |
| GET | `/api/tasks` | Получить все задачи | `200 OK` |
| GET | `/api/tasks/{id}` | Получить задачу по ID | `200 OK` |
| POST | `/api/tasks` | Создать задачу | `201 Created` |
| PUT | `/api/tasks/{id}` | Изменить задачу | `200 OK` |
| DELETE | `/api/tasks/{id}` | Удалить задачу | `204 No Content` |

POST и PUT принимают JSON без `id`, например:

```json
{
  "title": "Подготовить отчёт",
  "description": "Добавить скриншоты Swagger",
  "isCompleted": false
}
```

`title` обязателен и не может состоять только из пробелов. При неверных данных API возвращает `400 Bad Request`. Запрос по отсутствующему ID возвращает `404 Not Found`. ID назначается автоматически.

## Что сделать для сдачи

1. Запустите API и откройте Swagger.
2. Через POST создайте минимум три задачи, меняя `title` в теле запроса.
3. Выполните GET списка и GET одной задачи по её ID.
4. Через PUT измените название или статус одной задачи. Передайте все три поля JSON, поскольку PUT заменяет данные задачи.
5. Через DELETE удалите одну задачу и повторите GET списка, чтобы увидеть изменения.
6. Приложите проект, ответы из `CONTROL_QUESTIONS.md` и скриншоты.

Нужные скриншоты:

1. Swagger со всеми методами GET (список и по ID), POST, PUT, DELETE.
2. Результат GET со списком задач.
3. Результат POST с кодом `201` и созданной задачей.
4. Результат PUT с изменённой задачей или DELETE с кодом `204`.
