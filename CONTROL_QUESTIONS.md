# Ответы на контрольные вопросы

1. **Что такое Web API?** Интерфейс, через который программы обмениваются данными по HTTP.
2. **Для чего используется `[ApiController]`?** Включает удобное поведение API-контроллера, в том числе автоматический ответ `400` при ошибках проверки модели.
3. **Для чего используется `[Route]`?** Задаёт адрес, по которому доступны действия контроллера.
4. **Чем отличаются GET и POST?** GET получает данные, POST отправляет данные для создания нового ресурса.
5. **Чем отличаются PUT и DELETE?** PUT изменяет существующий ресурс, DELETE удаляет его.
6. **Что означают HTTP-коды 200, 201, 400 и 404?** `200` — запрос выполнен; `201` — ресурс создан; `400` — неверный запрос; `404` — ресурс не найден.
